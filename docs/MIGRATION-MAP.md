## 3) ترتيب العمل (Order)
1. **لوحة المدير والإعدادات** — الجهات، رموز الدعوة، الموافقة على الأعضاء.
2. **المكتبة** — التمارين + المهارات + الخطط المتحركة (نموذج v3 تحت المراجعة).
3. **السبورة التكتيكية + المراكز والأدوار** — مع أدوات الرسم الجديدة.
4. **اللاعبون** — الفرق، التقييم، الحالة البدنية.
5. **البرنامج اليومي + الوحدة التدريبية** — يسحبان من المكتبة واللاعبين.
6. **التطوير والبطولات** — الإدارة الفنية، مركز التعلّم، المرجع، البطولات.
7. **المباريات والتحليل** — قسم جديد كامل بأسلوب Play3.
8. **العمليات والتقارير.**
9. **صفحة الجهة.**

> كل قسم: تصميم يُعرض على محمد ← موافقة ← بناء ← مراجعة أن كل عناصر v28 فيه موجودة (بالعدد) ← تحديث هذا الملف.
