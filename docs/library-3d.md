# المكتبة — صور ثلاثية الأبعاد لكل تمرين (نوفمبر 2026)

**الاتجاه المعتمد:** الدمج بين (ج) دليل المدرب المحترف للمكتبة والبطاقة، و(أ) المسرح ثلاثي الأبعاد مع اللوحات الزجاجية العائمة.

## ما الذي يُبنى لكل تمرين
- **رقم مرجعي ثابت:** `IM-{اللعبة}-{التصنيف}-{رقم}`، ومحفوظ في `src/features/library/drill-refs.json`، ولا يتغير عند إضافة تمارين جديدة.
  - رموز الألعاب: FB قدم · FS صالات · BB سلة · HB يد · VB طائرة · GN عام.
  - رموز التصنيفات: WU إحماء · TE مهاري · TA خططي · GM لعب · PH بدني · CD تهدئة.
- **التصنيف الدولي:**
  - المرحلة السنية وفق نموذج LTAD.
  - الهدف، ويشمل الصفة البدنية في تمارين الإعداد البدني.
  - شكل التمرين.
  - إعدادات التصنيف في `catalog-config.json`.
- **مشهد ثلاثي الأبعاد** مبني من بيانات البطاقة نفسها:
  - الملعب الحقيقي بالمقاسات الرسمية.
  - المساحة المحددة بالأقماع.
  - عدد اللاعبين وأدوارهم.
  - المرمى أو السلة أو الشبكة.
  - الأدوات.
  - أسهم التمرير والجري والمراوغة والتسديد.
  - تمارين الإعداد البدني: لاعب بوضعية الجسم الصحيحة مع أدواته، في صالة أو صالة أثقال.

## الملفات (`src/features/library/arena3d/`)

| الملف | الدور |
|---|---|
| `athlete.ts` + `rig.json` | جسم اللاعب المفصلي (مقاسات الجسم في JSON) |
| `poses.json` | مكتبة الوضعيات (أكثر من 180 وضعية) |
| `exercises.json` | ربط كل تمرين بدني (198) بوضعيته وأدواته |
| `templates.ts` | تحويل بطاقة التمرين إلى وصف مشهد (`Spec`) |
| `build.ts` | بناء المشهد: الأرضية والخطوط والأدوات واللاعبون والأسهم |
| `render.ts` | رسم صورة كل بطاقة، وتخزينها في المتصفح (IndexedDB)، والمسرح التفاعلي |

## للتوسعة مستقبلًا
- **تمرين بدني جديد:** أضف سطرًا في `exercises.json` (الوضعية، والمكان، والأداة، والأدوات).
- **وضعية جديدة:** أضفها في `poses.json`.
- **تغيير شكل الصور بعد تعديل المحرك:** ارفع `IMAGE_VERSION` في `render.ts` حتى تُرسم الصور من جديد.
